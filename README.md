# NeProSto

**NeProSto — кроссплатформенный САПР для проектирования мебели и деревянных конструкций.** По 3D-модели редактор формирует ведомость деталей и рассчитывает длину заготовок с учётом торцевых запилов.

## Возможности

- Сборка изделий из панелей, досок и бруса. Детали можно выравнивать по опорным точкам и расставлять с равными зазорами.
- Моделирование сквозных и глухих отверстий, фальцев и запилов под углом.
- Редактируемые шаблоны кухонных шкафов, верстаков, садовых калиток и других изделий.
- Экспорт ведомости деталей в Excel.
