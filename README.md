# NeProSto

NeProSto — 3D-редактор для проектирования мебели и деревянных конструкций. В нём можно собрать шкаф, стеллаж или скамью и заранее выяснить, какие детали понадобятся в мастерской и какого размера их выпилить.

Работу можно начать с пустого проекта или с готовой модели. В редакторе вы задаёте размеры деталей, расставляете полки, выбираете материалы, намечаете отверстия и торцевые срезы. Линейка показывает расстояние между полками и зазоры между деталями. По готовой модели можно выгрузить список деталей в Excel или подготовить таблицу для БАЗИС-Раскрой.

NeProSto работает на macOS и в браузере. Проект можно сохранить в файл `.neprosto` и открыть позже.
